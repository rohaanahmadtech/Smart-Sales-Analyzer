# Smart Sales Data Analyzer
A mini data analytics project built using **NumPy, Pandas, and Matplotlib** to analyze and visualize business sales data.

---

# Features
*  Load and process CSV sales data
*  Data cleaning and preprocessing
*  Monthly & yearly sales analysis
*  Top-selling products identification
*  Region-wise performance analysis
*  Profit vs Cost insights
*  Data visualization using charts

---

# Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib
